Privacy policy

Last updated: 4 November 2026

autoanm is a private tool run by a single creator on their own computer. It signs in only to that creator's own Google account.

What it accesses

  • YouTube Data API: to upload videos, captions and video details to the creator's own channel, and to change a video's visibility or publish time.
  • YouTube Analytics API: to read view counts and audience retention for the creator's own videos.

What it stores

The sign-in token and the numbers it reads are stored only on the creator's own computer. Nothing is sold, shared with third parties, or used for advertising.

Removing access

Access can be withdrawn at any time from Google account permissions. Deleting the token file on the computer removes the stored data.

autoanm's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
